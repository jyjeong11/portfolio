Publications

01

Automated Cloud Risk Scoring via End-to-End CVE-ATT&CK Mapping and Flow Reconstruction

IEEE Access (SCIE, 2026) · 2저자

개요

  • 보안 점검 시 자주 쓰이는 두 정보, 즉 소프트웨어의 알려진 취약점 목록(CVE)과 해커들이 실제로 사용하는 공격 수법을 정리한 표준 체계(MITRE ATT&CK)는 서로 개별적으로 관리되어, 특정 취약점이 어떤 공격으로 이어질 수 있는지 자동으로 연결하기 어려웠음
  • 본 연구는 AI 언어 모델이 취약점 설명을 읽고 해당 공격 기법을 자동으로 찾아 연결하는 시스템을 제안함

주요 내용

  • 이 중 AI가 도출한 연결 결과가 실제로 근거 있는지 검증하는 모델 구축을 담당하여 취약점 설명 원문 안에서 AI의 판단을 뒷받침하는 근거를 스스로 찾아내도록 학습시키고, 근거를 찾지 못하면 결과를 그대로 신뢰하지 않고 걸러내도록 설계해, AI가 그럴듯하지만 근거 없는 결과를 내놓는 문제를 방지함
  • 해당 검증 모델이 취약점-공격 기법 연결 파이프라인에 적용된 결과, 취약점을 이용 가능한 실제 해킹 코드 79건으로 확인했을 때 예측된 공격 순서가 98.3% 정확히 일치
02

Container-Specific Service Mesh-based System for Mitigating Lateral Movement Attacks

IEEE Transactions on Cloud Computing (SCIE, 2026) · 5저자

개요

  • 기존에는 여러 컨테이너의 데이터를 한 곳에 모아 하나의 AI 모델로 공격자가 발생시키는 이상 징후를 판단하는 방식이 일반적이었지만, 역할이 다른 컨테이너는 정상 동작 패턴 자체가 달라 특정 컨테이너에서만 나타나는 이상 징후를 놓치기 쉬움
  • 본 연구는 컨테이너마다 별도의 AI 모델을 두어 이 문제를 해결하는 시스템을 제안

주요 내용

  • 컨테이너별로 학습된 모델을 지속적으로 갱신하는 학습 실험에 참여함
  • 전체를 총괄하는 서버와 각 컨테이너가 위치한 서버가 역할을 나눠, 검증된 정상 동작 데이터가 일정량 쌓이면 해당 컨테이너의 모델만 갱신하도록 구현
  • 검증을 거치지 않은 데이터는 학습에서 배제해 잘못된 패턴이 섞이지 않도록 함
  • 이를 통해 컨테이너가 새 버전으로 업데이트되어 동작 패턴이 바뀌어도 탐지 모델이 스스로 새로운 정상 패턴을 학습해 성능을 회복함
03

Lightweight Service Mesh for Intrusion Detection using KD-CNN in Cloud-Native Environments

Cloud Computing Security Workshop (국제 학회, 2025) · 4저자

개요

  • 클라우드 환경에서는 공격자가 컨테이너(하나의 서버를 여러 가상 서버로 나누는 기술) 하나에 침투하면 내부의 다른 컨테이너로 공격이 번지는 측면이동 공격이 위협이 됨
  • 본 연구는 각 컨테이너를 오가는 네트워크 데이터(트래픽)를 실시간으로 감시해 이상 징후를 탐지하는 경량 AI 시스템을 제안

주요 내용

  • 탐지 모델의 경량화 비교 실험에 참여함
  • 정상 데이터만으로 특징을 학습한 큰 모델(Teacher)의 판단 방식을 흉내내도록 학습시킨 여러 크기의 작은 모델(Student) 후보를 비교함
  • 크기를 줄일수록 정확도가 어느 지점부터 급격히 떨어지는지를 실험으로 확인해, 정확도와 처리 속도 사이에서 가장 합리적인 크기의 모델을 찾음
  • 최종 모델은 기존 방법들보다 탐지 정확도가 높았으며, 모델 크기를 큰 폭으로 줄이면서도 처리 속도는 오히려 빨라져 서버의 자원을 효율적으로 활용하는 방법을 습득함
